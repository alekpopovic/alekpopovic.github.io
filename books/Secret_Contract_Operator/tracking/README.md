# Development Tracking

All prompts are `pending`. Creating this book did not execute operator development.

Flow: pending -> in_progress -> implemented -> verified -> accepted. Use blocked when a dependency or decision is missing. Do not skip verified. Record the exact commit, commands actually run, and checks not run.

Medium and High describe task complexity, not automatic model configuration. Adapt actual supported settings to the chosen client without changing the security contract.

Phases A/B form the read-only MVP. Phase C introduces optional mutation. Phase D is advanced and is not required for the first release.
