## 3. Separate listener does not mean authenticated

NewDebugHandler registers pprof without its own auth middleware. Default loopback reduces exposure, but configurable ORCH_DEBUG_ADDR can broaden it. Restrict management access, bound captures, and treat profiles as sensitive. The chapter captured a synthetic benchmark profile without opening a listener. Prebuilt go tool pprof was absent; source-built go run cmd/pprof succeeded separately, with a short120ms CPU sample total.

## 4. Build a different production experiment

Pin images/cache state, services/replicas, update rate, constraints, authoritative durable store/schema, network path and readiness criterion. Measure API acceptance, scheduler computation, actual runtime start and application health separately. Include retained task/event history, database errors, partitions/recovery and exact cleanup. The tagged thousand-service test passed only task-count/iteration assertions with fake transitions. Running PostgreSQL beside that command does not make it a persistence benchmark. Record unresolved work rather than extrapolating a safe production maximum.
