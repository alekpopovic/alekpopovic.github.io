## 1. Read the fake's contract

Task-key replay and operation history support agent idempotency/order assertions. FakeRuntime does not enforce kernel cgroups or real port binding, so a successful fake start cannot prove memory or CPU limits. Assert supplied ContainerSpec fields and separately inspect a real engine when claiming enforcement.
