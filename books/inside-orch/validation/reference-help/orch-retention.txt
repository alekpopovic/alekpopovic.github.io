Inspect and run retention pruning

Usage:
  orch retention [command]

Available Commands:
  prune       
  status      

Flags:
  -h, --help   help for retention

Global Flags:
      --config string      CLI config file (default "<home>/.config/orch/config.yaml")
  -n, --namespace string   workload namespace
      --output string      output format: table or json (default "table")
      --server string      control-plane server URL
      --token string       user API JWT bearer token

Use "orch retention [command] --help" for more information about a command.
