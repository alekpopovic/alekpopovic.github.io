# Inside orch

**Building and Operating a Docker Orchestrator in Go**  
By **Aleksandar Popovic** · English · Edition 1.0 · October 13, 2026

Trace a real Go/Docker orchestrator from executable composition to task placement, agents, rollout, security, jobs, local storage and recovery. The book follows exact source and historical evidence, demonstrates practical failure windows and distinguishes active runtime paths from implemented packages and proposed improvements.

The edition contains a preface, forty numbered chapters, six reference appendices, forty worked chapter-answer companions, twenty-four additional audience exercises and eight separately recorded laboratories. The measured meaningful manuscript is approximately 101,000 words; code listings and raw test output are excluded from that editorial count. PDF page count is measured after final typesetting.

Developers can follow domain/HTTP/CLI, scheduling and reconciliation before jobs and test design. Operators can begin with process restart, agents, rollout, secret custody and bounded restore experiments. Architects can compare state ownership, atomic claims, namespace boundaries, leadership and actual composition. Each route retains explicit prerequisites and failure limits.
