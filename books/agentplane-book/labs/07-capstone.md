# The End-to-End Vertical Slice

## Prerequisites

A separate AgentPlane implementation repository; the book is not that application.

## Procedure

Follow Chapter 27. Use two tenants, a harmless workload, a governed test tool and synthetic data. Include one network partition, one replay and one scoped export attempt.

## Acceptance criteria

Publish a traceability matrix linking each claim to test evidence. Show observed-state age, pending termination and unknown outcomes honestly. Mark unavailable integrations blocked; do not label the complete product production-ready.

## Evidence record

Record date, source revision, environment, exact commands, expected result, actual result, limitations and teardown status. Never attach secrets or customer payloads. A written procedure is not an executed result.
