# Start Here

Open a new implementation repository. Copy the implementation contract into that
repository's instructions, then run assignment 00 before continuing in order.
Keep this book available as read-only context. Do not run all assignments as an
unattended deployment job.

Choose an available coding model through the tool's documented interface.
`security-critical` is a review label, not a setting to paste into a model API.
Codex, another coding assistant or a human developer can use the assignments,
provided they follow the repository's actual authorization and tooling rules.
