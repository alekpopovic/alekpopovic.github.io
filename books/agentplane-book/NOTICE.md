# Origin, Scope and Project Status

AgentPlane is the working name of the reference platform designed in this book.
This is an independent educational publication, not official documentation of
Kubernetes, CNCF, OpenAI or agentgateway. No affiliation or endorsement is claimed.

The edition was prepared with AI assistance from the AgentPlane architecture and
implementation discussion. A publisher should review technical claims, licenses,
attribution and repository security settings before public release. There are no
invented contributors, customers, certifications, benchmark results or adoption
statistics.

**Version 0.1.0 identifies the book, not a released AgentPlane application.**
The repository includes an authored handbook, teaching examples, local checks,
implementation prompts and a static-book builder. It does not contain a complete
SaaS, production operator, production PKI or independently audited sandbox.

Primary sources appear in [book/references.md](book/references.md). Actual checks
and limitations appear in [reports/VALIDATION.md](reports/VALIDATION.md).

The HTML edition uses original CSS, system fonts and local SVG
assets. It does not require analytics, web fonts or CDN requests to be read.
Mistune is a build dependency; its implementation is not vendored here.
