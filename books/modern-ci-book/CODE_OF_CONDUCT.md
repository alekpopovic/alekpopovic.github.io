# Community conduct

Discuss technical ideas respectfully. Critique behavior and evidence rather than personal characteristics. Harassment, threats, discriminatory abuse, doxxing, and disclosure of private credentials or personal information are not acceptable.

Maintainers may edit or remove harmful content and limit participation. Explain moderation decisions when doing so does not expose private information. For a sensitive concern, request a private contact route without posting details publicly.

Apply these expectations in issues, reviews, discussions, and other project spaces.
