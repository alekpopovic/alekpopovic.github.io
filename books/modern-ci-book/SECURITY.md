# Security policy

This repository contains educational examples and a platform design, not a supported production deployment. Do not expose the laboratory as a service or give it production credentials.

For a vulnerability in the examples or a dangerous documented procedure, use the repository's private vulnerability-reporting feature if the maintainer has enabled it. Otherwise, open an issue requesting a private contact route without including exploit details, secrets, or private infrastructure data. Maintainers should configure that route before inviting security reports.

Include the affected edition, a minimal local reproduction, impact, and a suggested correction when possible. No response-time service level is promised. A fix should update both the code and the chapter that explains it.
