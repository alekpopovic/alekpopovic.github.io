# LogBranik / Nginx Log Security

A complete publication-candidate field guide for Leanpub: twenty lessons, a preface, three appendices, editable Markdown, an executed Python teaching lab, a sixty-task production implementation pack, branding, PDF/EPUB editions and samples.

Start with output/nginx-log-security.pdf. Edit lessons/*.md and regenerate with tools/build_book.py. See companion/README.md for the lab and publishing/PUBLISHING_SR.md for the owner's publication workflow. The author is **[Aleksandar Popovic](https://github.com/alekpopovic)**. Independent review and actual deployment acceptance remain pending. No publication has been performed.
