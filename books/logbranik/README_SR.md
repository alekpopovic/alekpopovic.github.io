# LogBranik / Nginx Log Security

Kompletan radni paket za Leanpub: 20 lekcija na engleskom, predgovor i tri dodatka, Markdown izvori, prateći Python laboratorijski kod, originalni Claude Code paket, SVG branding, korice, PDF/EPUB i besplatan uzorak.

Počni od `output/nginx-log-security.pdf`. Za uređivanje koristi `lessons/`. Za praktični rad koristi `companion/README.md`. Za objavljivanje pogledaj `publishing/PUBLISHING_SR.md`.

## Sadržaj

| Putanja | Sadržaj |
| --- | --- |
| `lessons/*.md` | Izvori svih lekcija i dodataka |
| `manuscript/` | Leanpub poglavlja, Book.txt, Sample.txt i resursi |
| `companion/` | Laboratorijski kod, testovi i produkcioni dizajn |
| `branding/` | SVG logoi, korice, paleta i smernice |
| `publishing/` | Prodajni tekst i koraci za objavljivanje |
| `output/` | PDF, EPUB, uzorci i spojeni Markdown |
| `tools/` | Ponovljiv izvoz i provera |
| `verification/` | Stvarna evidencija izvršenih provera |

Autor: **[Aleksandar Popovic](https://github.com/alekpopovic)**. Otvoreni kandidat za objavljivanje, izdanje 0.2. Nije automatski odobreno produkciono rešenje. Pre komercijalnog izdanja potrebna je ljudska stručna recenzija i prihvatanje odgovarajućih host testova. Ime LogBranik je predlog brenda. Paket ne sadrži generisane privatne ključeve ili izmišljenu biografiju.
