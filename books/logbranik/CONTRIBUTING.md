# Contributing

Author and maintainer: Aleksandar Popovic — https://github.com/alekpopovic.

Edit lesson sources in `lessons/*.md`, not generated `manuscript/*.txt` or ebooks.
Keep examples scoped to an authorized local laboratory. Describe which checks
you actually ran; do not turn an unexecuted production design into a tested claim.

Regenerate with `python3 tools/create_branding.py`, `python3 tools/build_book.py`
and `python3 tools/validate_release.py`. Review changed PDF pages and EPUB
metadata. For code changes, also run the relevant companion tests.

Contributions are distributed under the license applying to their material:
CC BY 4.0 for prose and original visual assets, MIT for code and configuration.
Retain attribution and third-party notices; identify outside sources and their
licenses. Explain corrections and include meaningful verification evidence.

Repository URL has not yet been assigned. The author profile is a contact and
identity link, not a claim that this package has already been published there.
