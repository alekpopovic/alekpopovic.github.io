# alekpopovic.github.io

Personal website for Aleksandar Popovic, built with Ruby, Jekyll, and Tailwind CSS.

## Local development

Install dependencies:

```sh
bundle install
npm install
```

Build Tailwind once:

```sh
npm run build
```

Run the Jekyll server:

```sh
npm run dev
```

For active styling work, run Tailwind in a second terminal:

```sh
npm run watch
```
