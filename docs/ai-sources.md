# AI Lab editorial sources

The initial eight articles were checked on October 10, 2026. The six command
references contain compact factual command inventories and original worked
examples, not copies of the documentation's explanations. The two workflow
articles provide original editorial scenarios. Commands depend on the product,
version, account, policy, and installed extensions; the app's local menu remains
the final discovery surface.

| Guide | Scope and source |
| --- | --- |
| ChatGPT | [Desktop slash commands](https://learn.chatgpt.com/docs/reference/slash-commands), with [web/CLI scope](https://learn.chatgpt.com/docs/developer-commands) clearly separated |
| Codex | [Codex CLI command table](https://learn.chatgpt.com/docs/developer-commands?surface=cli), including aliases and conditional entries |
| Claude Code | [Command reference](https://code.claude.com/docs/en/commands), including bundled skills, aliases and retired entries; [skills](https://code.claude.com/docs/en/skills) are identified separately |
| Gemini CLI | [Command families and subcommands](https://geminicli.com/docs/reference/commands/), [custom commands](https://geminicli.com/docs/cli/custom-commands/), and [project context](https://geminicli.com/docs/cli/gemini-md/) |
| Cursor | [CLI slash-command reference](https://cursor.com/docs/cli/reference/slash-commands), including its listed aliases; editor menus are not implied |
| GitHub Copilot | Every command in [GitHub's VS Code cheat sheet](https://docs.github.com/en/copilot/reference/chat-cheat-sheet?tool=vscode), which explicitly describes a common-command list; [VS Code's feature reference](https://code.visualstudio.com/docs/agents/reference/ai-features-cheat-sheet) identifies prompt-file extensions |

Individual articles retain direct source links and a `verified_at` date. Updating
a date requires checking the sources again. Do not claim an exhaustive inventory
of custom plugins, private skills, or commands available in a reader's account.
Future guides inherit the Google tag through the shared post/default layouts.
