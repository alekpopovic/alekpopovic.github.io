`alekpopovic.github.io` is the public home for the personal site itself. It keeps the portfolio, writing, open source notes, CodePop link, and BugSonar link in one lightweight GitHub Pages project.

The useful part of a site repo is that it can evolve in the open. The content, styling, deployment workflow, and structure all live next to each other, so the site can change as the work changes.
