One small, local workspace

For the downloadable workspace, you need Node.js 20+ and a terminal. The editor above runs the same exercise assertions in your browser. The exercises have no dependencies to install, make no network calls, and need no API key. Codex CLI is the documented coding-assistant surface; you can also solve the tasks yourself. Using an AI assistant requires that tool's own installation and account.

Each starter intentionally fails its tests. Edit its app.mjs, rerun the check, and compare the worked solution after your attempt. A passing test demonstrates the stated exercise contract.

unzip ai-workshops.zip
cd ai-workshops
node verify.mjs bugfix
